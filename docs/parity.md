Implemented shell commands: `pwd`, `whoami`, `cd`, `ls`, `mkdir`, `rm`, `mv`, `cp`, `echo`, `cat`, `true`, `false`, `head`, `tail`, `wc`, `sort`, `uniq`, `grep`. Options and input modes are limited. `grep` uses bounded Rust regular expressions. Shell expansions and compound syntax fail explicitly. Background syntax is rejected because durable spawn does not exist.

## Completion gates

1. Port the missing process/terminal and language contracts with real native-runtime tests. QuickJS does not provide Node compatibility.
2. Complete the Rust WASI syscall plane, process options, shared durable files and software packages. The upstream browser bridge uses SharedArrayBuffer/Web Workers; Cloudflare Workers has no threading and cannot use it unchanged.
3. Complete language package resolution and filesystem integration, then compare actual upstream fixtures. Evaluate native Rust compilation and native Cloudflare runtime support before adding alternate execution infrastructure.
4. Implement durable execution recovery, cancellation, stdio replay, schedules and previews with R2 as application data owner. Define and test effects under interruption/reconnection.
5. Validate Queue backlog/fairness and performance at large file/process inventories, CPU/memory exhaustion, concurrent agents and cold language startup.
6. Deploy using the minutei profile, validate the same flows against the remote Worker, and verify remote CI independently.

The current implementation passes the implemented-boundary tests; these gates are open. There is no total-parity or production-readiness claim.

`bun run software:proof` validates the published jq artifact with SHA-256 `edb1cf0bbcf663d177916592d2f1b4361a02966dbf2eb44e3e61ea2a399bb43a`, installs it and exercises version, stdin, filters, file input and a shell pipeline against `CIRRO_URL`. Host libc imports support one-shot file creation modes, hidden pathname preopens that survive closing fd 3, and anonymous temporary files with descriptor lifetime, sandbox grants and readonly package guards. Direct I/O is explicitly unsupported; network send/recv on regular files returns NOTSOCK. This does not establish compatibility for other release packages.

Internal Rust heap restoration is verified in replacement workerd instances with R2 pages: fuel continuation, handler frames/masks, and parent/child pipe/wait state. Queued WASI handover now uses the receipt/Queue lifecycle, retains original grants/deadlines and restores kernel/stdio state, including a parent waiting for a child or stopped until the child sends SIGCONT. Arbitrary-crash recovery and the external-effect intent boundary remain open.

Root filesystem export preserves binary files, modes, ownership and symlink targets from one confirmed manifest with an exact serialized byte limit. Native workerd tests cover guest access, replacement Workers, concurrent batch writes, permission failures and corrupt R2 blocks. Mounts and snapshot import remain open.

WASI Preview 1 `fd_advise` accepts the six standard hints after checking descriptor rights, file type, enum and unsigned range overflow. Advice does not change bytes, offsets or file size in the in-memory guest cache. The native Cargo fixture verifies this ABI in workerd, including descriptors opened without the advice right. `bun run advice:proof` verifies the same fixture and retained file bytes against `CIRRO_URL`. This closes one import gap; CPython still requires other WASI imports and a validated standard-library filesystem.
